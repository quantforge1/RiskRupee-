2. PROBLEM & SOLUTION

Organizations commonly manage cybersecurity risk using qualitative red/amber/green heat maps and periodic audits. This makes it difficult for boards and CFOs to compare cybersecurity investments with other financial decisions, while security teams struggle to prove ROI.

RiskRupee solves this by:

1. Continuously quantifying cyber risk in ₹ Lakh/Crore using a FAIR-style model.
2. Calculating Annualized Loss Expectancy (ALE) and Value-at-Risk (VaR) using simulated/Monte Carlo analysis.
3. Maintaining a risk register covering realistic cyber scenarios.
4. Solving a constrained optimization problem to recommend the best security-control allocation for a given budget.
5. Providing an India-specific compliance layer covering CERT-In, RBI, SEBI CSCRF and DPDP.
6. Translating plain-English threats into financial cyber-risk scenarios.
7. Producing board-ready reports in English/Hindi.

5. WOW FEATURES — PRIORITY

These are the centerpiece of the application and must receive the highest implementation and visual priority.

5.1 Investment Optimizer + Efficient Frontier

Create an interactive security-budget allocator.

User can:

- Set a total security budget with a slider/input.
- See candidate controls with cost and estimated risk reduction.
- Toggle controls manually.
- Compare manual allocation against mathematically optimal allocation.
- See the risk reduction change immediately.
- Apply the recommended allocation.

Use a client-side constrained optimization algorithm such as greedy/0-1 knapsack:

Goal: maximize total ΔALE subject to the available budget.

Show:

- Efficient Frontier scatter/line chart.
- X-axis = security spend.
- Y-axis = risk reduction.
- Clearly highlighted optimal point.
- User's manual allocation point.
- Connecting curve/frontier.
- Control cost-vs-risk-reduction visualization.
- Gordon-Loeb reference/guardrail indicating a recommended ceiling of approximately 37% of expected loss.

Dragging the budget slider must visibly change the optimal allocation and chart in real time.

Debounce expensive calculations around 150–250 ms so interaction remains smooth.
